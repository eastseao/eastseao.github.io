# 地平线 · 王维的个人主页

重新设计的个人主页，基于 [pseudoyu.com](https://www.pseudoyu.com/) 的极简结构，收录原 [horizon 博客](https://github.com/eastseao/horizon) 的全部内容。

## 内容结构

| 视图 | 内容 |
| --- | --- |
| 首页 | 问候、身份、简介、内容入口、社交链接 |
| 文章 | 43 篇文章（2020–2025），按年份分组，支持搜索与展开阅读 |
| 兴趣 | 爱好 / 书 / 音乐 / 系列 / 游戏 |
| 随手拍 | 风景 / 人物 / 生活 / 猫 / 随手拍 共 33 张照片，支持灯箱预览 |
| 驻足点 | 2004–2025 年走过的城市时间轴 |
| 关于 | 工作、爱好、站点由来、联系方式 |

## 技术说明

- 单页应用：`index.html`（原生 HTML/CSS/JS，hash 路由，无构建依赖）
- 图片位于 `assets/`（沿用原站素材）
- 字体：Noto Serif SC + Noto Sans SC（自托管镜像）

## 本地预览

直接用浏览器打开 `index.html` 即可。
